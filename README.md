- **Game Platforms**: Auto API for Juwa, Juwa2.0, Vegas Sweeps, Game Vault, E-Star, Dragon Fury, Ultra Thunder, Fire Kirin; all other titles are manual admin flow.
- **Game API env setup**: see [GAME_CREDENTIALS_GUIDE.md](./GAME_CREDENTIALS_GUIDE.md).

- **Security & Alerts**: USA Twilio SMS OTP verification, Nodemailer SMTP emails, Web Chrome notifications, and WhatsApp live chat.
- **Database**: High-performance MongoDB Atlas Cloud.
